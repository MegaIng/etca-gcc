Introduction ¶

This manual describes how to use gdc, the GNU compiler for the D programming language. This manual is specifically about how to invoke gdc, as well as its features and incompatibilities. For more information about the D programming language in general, including language specifications and standard package documentation, see https://dlang.org/.
